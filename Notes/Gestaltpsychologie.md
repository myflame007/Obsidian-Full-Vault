## Grundprinzip

### Ganzheitlichkeit

> **"Das Ganze ist etwas Anderes als die Summe seiner Teile"** — Oft Max
> Wertheimer zugeschrieben

**Bedeutung:**

-   Psychische Phänomene können nicht auf Einzelelemente reduziert werden
-   Die Gesamtheit hat eigene Qualitäten (emergente Eigenschaften)
-   Wahrnehmung ist aktive Organisation, nicht passive Aufnahme

### Beispiel: Melodie

-   Eine Melodie ist mehr als die Summe einzelner Töne
-   Transponiert man sie, bleiben alle Töne verschieden, aber die Melodie bleibt
    erkennbar
-   Die **Struktur** (Gestalt) bleibt erhalten

## Die Gestaltgesetze

### Gesetz der Prägnanz (Überbegriff)

> Wir nehmen Reize so wahr, dass sie möglichst **einfach, regelmäßig und
> symmetrisch** erscheinen.

### Die wichtigsten Gesetze

| Gesetz                    | Beschreibung                                          | Illustration     |
| ------------------------- | ----------------------------------------------------- | ---------------- |
| **Nähe**                  | Nahe Elemente werden als zusammengehörig wahrgenommen | ●● ●● → 2 Paare  |
| **Ähnlichkeit**           | Ähnliche Elemente werden gruppiert                    | ●●○○●● → Gruppen |
| **Gute Fortsetzung**      | Linien werden als fortlaufend gesehen                 | X = zwei Linien  |
| **Geschlossenheit**       | Tendenz zur Vervollständigung                         | ◠ → Kreis        |
| **Gemeinsames Schicksal** | Zusammen bewegte Elemente = zusammengehörig           |                  |
| **Verbundenheit**         | Verbundene Elemente = zusammengehörig                 |                  |

## Kurt Lewins Feldtheorie

### Grundformel

```
V = f(P, U)
```

-   **V** = Verhalten (Behavior)
-   **P** = Person
-   **U** = Umwelt (Umfeld)
-   Verhalten ist immer Funktion von Person UND Situation

### Zentrale Konzepte

| Konzept             | Bedeutung                           |
| ------------------- | ----------------------------------- |
| **Lebensraum**      | Psychologische Umwelt einer Person  |
| **Valenz**          | Aufforderungscharakter von Objekten |
| **Positive Valenz** | Zieht an (Annäherung)               |
| **Negative Valenz** | Stößt ab (Vermeidung)               |
| **Kraft**           | Stärke der Anziehung/Abstoßung      |

### Konflikttypen nach Lewin

| Typ                       | Beschreibung                                | Beispiel                     |
| ------------------------- | ------------------------------------------- | ---------------------------- |
| **Annäherung-Annäherung** | Zwei positive Ziele                         | Kuchen oder Eis?             |
| **Vermeidung-Vermeidung** | Zwei negative Optionen                      | Zahnarzt oder Zahnschmerzen? |
| **Annäherung-Vermeidung** | Ziel ist gleichzeitig attraktiv und aversiv | Prüfung: Erfolg vs. Angst    |

## Das Phi-Phänomen

**Entdeckung, die die Gestaltpsychologie begründete (1912)**

### Experiment

-   Zwei Lichtpunkte werden nacheinander präsentiert
-   Bei richtigem Zeitabstand: Wahrnehmung einer **Bewegung**
-   Obwohl nichts sich tatsächlich bewegt!

### Bedeutung

-   Beweis gegen Elementarismus
-   Das Gehirn **konstruiert** die Bewegung
-   Grundlage für Film und Animation

---

## Köhlers Schimpansen-Experimente

### Einsichtslernen

**Experiment:**

-   Schimpanse Sultan
-   Banane außer Reichweite
-   Stöcke im Käfig

**Ergebnis:**

-   Plötzliche Lösung (Aha-Erlebnis)
-   Zusammenstecken der Stöcke
-   Keine graduelle Annäherung

**Schlussfolgerung:**

-   Lernen durch **Einsicht**, nicht nur Versuch-und-Irrtum
-   Umstrukturierung des Wahrnehmungsfeldes
-   Gegen behavioristische Lerntheorie

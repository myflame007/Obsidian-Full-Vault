# User Roles Manager

## Einordnung

- Bereich: Security & Administration
- Hersteller: MscrmTools
- Version: 1.2024.5.10

## Kurzbeschreibung

Allows to edit user/team and roles association in bulk

Praktisch vor allem dann, wenn der Standardweg in Dataverse zu langsam oder zu umstaendlich ist.

## Wann ich es nutze

- Wenn ich Security- oder Admin-Themen ohne eigenes Script analysieren will.
- Wenn ich Rollen, Zugriffe oder Einstellungen schneller pruefen und anpassen muss.
- Wenn ich operative Supportfaelle in Dataverse effizienter loesen will.

📌 Gängige Tags für Atomic Commits

feat:      🚀 Fügt ein neues Feature hinzu
fix:       🐛 Behebt einen Bug
refactor:  🔧 Code-Änderung, die keine neue Funktion oder Fix ist
docs:      📖 Dokumentation aktualisiert (README, Kommentare, Doku)
test:      ✅ Tests hinzugefügt/geändert
chore:     🛠 Allgemeine Aufgaben, die keine Funktion ändern (CI/CD, Linter)
perf:      ⚡ Performance-Optimierung
style:     🎨 Nur Code-Stil-Änderungen (Formatierung, Leerzeichen, Semikolons)
ci:        🔄 CI/CD Konfigurationen oder Pipelines angepasst
build:     🏗 Änderungen am Build-Prozess oder an Abhängigkeiten
revert:    ⏪ Einen früheren Commit rückgängig machen

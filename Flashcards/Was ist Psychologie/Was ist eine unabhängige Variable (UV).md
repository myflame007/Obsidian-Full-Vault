Q: Was ist eine unabhängige Variable (UV)?
A: In einem Experiment ist die unabhängige Variable (UV) die Variable, die vom Versuchsleiter bewusst und systematisch manipuliert (verändert) wird, um ihre Auswirkung auf eine andere Variable zu untersuchen.
Hint: UV = Ursache, wird manipuliert.

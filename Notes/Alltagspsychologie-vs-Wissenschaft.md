# Alltagspsychologie vs. wissenschaftliche Psychologie

> Warum wir wissenschaftliche Methoden brauchen

---

## Überblick

| Aspekt      | Alltagspsychologie     | Wissenschaftliche Psychologie |
| ----------- | ---------------------- | ----------------------------- |
| **Basis**   | Persönliche Erfahrung  | Systematische Forschung       |
| **Methode** | Intuition, Heuristiken | Wissenschaftliche Methode     |
| **Prüfung** | Keine systematische    | Empirische Überprüfung        |
| **Ziel**    | Alltag bewältigen      | Fundierte, prüfbare Aussagen  |

---

## Warum der "gesunde Menschenverstand" oft falsch liegt

### Kognitive Verzerrungen (Biases)

```
Wahrnehmung → [kognitive Filter] → verzerrte Interpretation
```

**Hauptverzerrungen:**

| Verzerrung             | Englisch          | Beschreibung                                                         | Beispiel                                                     |
| ---------------------- | ----------------- | -------------------------------------------------------------------- | ------------------------------------------------------------ |
| **Rückschaufehler**    | Hindsight Bias    | Nach Kenntnis eines Ereignisses glauben, man hätte es vorher gewusst | "Das war doch klar, dass die Beziehung scheitert!"           |
| **Bestätigungsfehler** | Confirmation Bias | Informationen bevorzugen, die eigene Meinung bestätigen              | Nur Nachrichten lesen, die eigene politische Meinung stützen |

## Heuristiken

> Faustregeln für schnelle Entscheidungen bei unvollständigen Informationen

### Vorteile und Nachteile

| Vorteil                    | Nachteil                            |
| -------------------------- | ----------------------------------- |
| Schnelle Entscheidungen    | Systematische Fehler                |
| Wenig kognitive Ressourcen | Ignorieren relevanter Informationen |
| Oft "gut genug"            | Versagen bei komplexen Problemen    |

### Repräsentativitätsheuristik

**Definition:** Annahme, dass typischere Ereignisse wahrscheinlicher sind

**Klassisches Beispiel - Münzwurf:**

| Sequenz | Erscheint...       | Tatsächliche Wahrscheinlichkeit |
| ------- | ------------------ | ------------------------------- |
| KZZKZ   | "zufällig"         | 1/32 (3,125%)                   |
| KKKKK   | "unwahrscheinlich" | 1/32 (3,125%)                   |

> Beide Sequenzen sind **gleich wahrscheinlich!**

### Verfügbarkeitsheuristik

**Definition:** Je leichter Beispiele einfallen, desto häufiger wird etwas
eingeschätzt

**Beispiel:** Flugzeugabstürze werden als häufiger eingeschätzt als Autounfälle,
weil sie medienwirksamer sind - obwohl Autofahren statistisch viel gefährlicher
ist.

## Kritisches Denken

> Der erste Schritt zur Wissenschaftlichkeit

### Die 3 Kernfragen

```
1. WOHER kommt die Information?
   ↓
2. WAS GENAU wird behauptet?
   ↓
3. Gibt es GENUG EVIDENZ?
```

### Merkmale kritischen Denkens

| Merkmal                         | Beschreibung                          |
| ------------------------------- | ------------------------------------- |
| **Systematisches Hinterfragen** | Nicht alles unhinterfragt akzeptieren |
| **Quellenbewertung**            | Wer sagt es? Warum?                   |
| **Evidenzprüfung**              | Gibt es Belege? Wie gut sind sie?     |
| **Alternativerklärungen**       | Gibt es andere Möglichkeiten?         |

## Beispiele aus dem Alltag

### "Ich kenne da jemanden, der..."

**Problem:** Einzelfälle sind keine Evidenz

| Alltagsaussage                       | Wissenschaftliche Perspektive             |
| ------------------------------------ | ----------------------------------------- |
| "Mein Opa hat geraucht und wurde 95" | N=1, keine Kontrolle von anderen Faktoren |
| "Homöopathie hat mir geholfen"       | Placeboeffekt, Spontanheilung möglich     |

### Warum wir trotzdem an Alltagspsychologie glauben

1. **Schnelles Feedback** - Intuition funktioniert oft "gut genug"
2. **Selektive Erinnerung** - Treffer werden erinnert, Fehler vergessen
3. **Kausalitätsillusion** - Korrelation wird als Ursache interpretiert
4. **Sozialer Konsens** - "Alle sagen das"

# Power Platform - Umgebung und Benutzerzugriff

## Sichtbarkeit der Umgebung im Admin Center

- **Security Gruppe**: Eine Umgebung ist im Admin Center nur sichtbar, wenn man Mitglied der entsprechenden Security Gruppe der Umgebung ist
- **System User**: Als System User kann man die Umgebung im Admin Center sehen
- **System Customizer**: Als System Customizer kann man die Umgebung in Power Apps sehen
- **Contributor**: Als Contributor sollte man die Umgebung ebenfalls sehen können

## Benutzerverwaltung prüfen

- Unter **Benutzer → "See All"** kann man alle Benutzer der Umgebung einsehen
- Wenn sich ein Benutzer in der Power App in der Umgebung anmeldet und der Login erfolgreich war, taucht er automatisch in der Benutzerliste auf
- Ein Benutzer kann auch **manuell hinzugefügt** werden

## Diagnose & Troubleshooting

- **Run Diagnostics**: Kann zusätzliche Informationen liefern, wenn man auf einen Benutzer klickt und die Detailansicht öffnet

## Zugriff auf die App

- Neben dem Umgebungszugriff muss der **Zugriff auf die App selbst** separat vergeben werden

# Operationalisierung

> Vom abstrakten Konzept zur messbaren Variable

---

## Der Weg von der Idee zur Zahl

```
Merkmal (Eigenschaft einer Person)
        ↓ Operationalisierung
Variable (messbare Größe)
        ↓ Messung
Daten (Zahlenwerte)
```

---

## Zentrale Begriffe

| Begriff                 | Definition                                   | Beispiel                                  |
| ----------------------- | -------------------------------------------- | ----------------------------------------- |
| **Merkmal**             | Eigenschaft eines Objekts/einer Person       | Intelligenz, Angst, Körpergröße           |
| **Operationalisierung** | Festlegung, wie ein Merkmal gemessen wird    | "Intelligenz = IQ-Testwert"               |
| **Variable**            | Das operationalisierte Merkmal               | IQ-Wert (kann variieren: 80, 100, 120...) |
| **Messung**             | Zuordnung von Zahlen zu Merkmalsausprägungen | Person A → IQ 105                         |

---

## Latente vs. Manifeste Merkmale

### Überblick

| Art          | Beschreibung             | Messung                   | Beispiele                                      |
| ------------ | ------------------------ | ------------------------- | ---------------------------------------------- |
| **Manifest** | Direkt beobachtbar       | Direkte Messung           | Körpergröße, Reaktionszeit, Blutdruck          |
| **Latent**   | Nicht direkt beobachtbar | Indirekt über Indikatoren | Intelligenz, Angst, Motivation, Persönlichkeit |

### Das Problem der latenten Merkmale

```
Latentes Merkmal: ANGST
         ↓
         ? (nicht direkt messbar)
         ↓
Manifeste Indikatoren:
- Herzfrequenz erhöht
- Selbstbericht ("Ich fühle mich ängstlich")
- Vermeidungsverhalten
- Cortisol im Speichel
```

> Bei latenten Merkmalen: **Rückschluss** von manifesten Indikatoren auf das
> latente Konstrukt!

### Beispiel: Operationalisierung von "Stress"

| Indikator-Typ             | Messung                | Vor- und Nachteile       |
| ------------------------- | ---------------------- | ------------------------ |
| **Physiologisch**         | Cortisol, Herzfrequenz | Objektiv, aber aufwändig |
| **Selbstbericht**         | Fragebogen (PSS)       | Einfach, aber subjektiv  |
| **Verhaltensbeobachtung** | Fehler bei Aufgaben    | Objektiv, aber indirekt  |

## Psychometrische Gütekriterien

### Die 3 Hauptkriterien

| Kriterium        | Definition                         | Kernfrage                                     | Prüfung                   |
| ---------------- | ---------------------------------- | --------------------------------------------- | ------------------------- |
| **Objektivität** | Unabhängig von der Versuchsleitung | Kommen verschiedene VL zum gleichen Ergebnis? | Interrater-Reliabilität   |
| **Reliabilität** | Zuverlässigkeit, Messgenauigkeit   | Gleiches Ergebnis bei Wiederholung?           | Test-Retest, Split-Half   |
| **Validität**    | Misst, was es zu messen vorgibt    | Misst der IQ-Test wirklich Intelligenz?       | Korrelation mit Kriterien |

### Arten der Objektivität

| Art                             | Beschreibung                                 |
| ------------------------------- | -------------------------------------------- |
| **Durchführungsobjektivität**   | Standardisierte Instruktion und Durchführung |
| **Auswertungsobjektivität**     | Klare Auswertungsregeln                      |
| **Interpretationsobjektivität** | Eindeutige Normen für Interpretation         |

### Arten der Validität

| Art                     | Frage                                              | Beispiel                                          |
| ----------------------- | -------------------------------------------------- | ------------------------------------------------- |
| **Inhaltsvalidität**    | Deckt der Test alle relevanten Aspekte ab?         | Matheklausur prüft alle gelehrten Themen          |
| **Kriteriumsvalidität** | Korreliert der Test mit relevanten Außenkriterien? | IQ korreliert mit Schulnoten                      |
| **Konstruktvalidität**  | Misst der Test das theoretische Konstrukt?         | Angstfragebogen korreliert mit anderen Angstmaßen |

### Hierarchie der Gütekriterien

```
Validität (höchstes Ziel)
    ↑ setzt voraus
Reliabilität
    ↑ setzt voraus
Objektivität (Grundvoraussetzung)
```

> Ein Test kann reliabel sein, ohne valide zu sein (z.B. konsistent das Falsche
> messen)!

## Skalenniveaus

### Die 4 Stufen

| Niveau         | Eigenschaften           | Beispiel                      | Mögliche Aussagen  | Erlaubte Operationen |
| -------------- | ----------------------- | ----------------------------- | ------------------ | -------------------- |
| **Nominal**    | Kategorien              | Geschlecht, Nationalität      | Gleich/Verschieden | Häufigkeiten         |
| **Ordinal**    | + Rangordnung           | Schulnoten, Bildungsabschluss | Größer/Kleiner     | Median               |
| **Intervall**  | + gleiche Abstände      | Temperatur (°C), IQ           | Differenzen        | Mittelwert           |
| **Verhältnis** | + natürlicher Nullpunkt | Reaktionszeit, Gewicht        | Verhältnisse       | Alle Rechenarten     |

### Merkhilfe

```
N ominell   = N amen (Kategorien)
O rdinal    = O rdnung (Rangreihe)
I ntervall  = I mmer gleiche Abstände
V erhältnis = V ollständig (echter Nullpunkt)
```

### Beispiele im Detail

**Intervall vs. Verhältnis - warum wichtig?**

| Skala      | Beispiel         | 0 =                              | Aussage "doppelt so viel"                            |
| ---------- | ---------------- | -------------------------------- | ---------------------------------------------------- |
| Intervall  | Temperatur in °C | willkürlich (gefrierende Wasser) | 20°C ist nicht "doppelt so warm" wie 10°C            |
| Verhältnis | Kelvin           | absoluter Nullpunkt              | 200K ist doppelt so viel thermische Energie wie 100K |

## Variablenarten

### Nach Ausprägungen

| Art          | Beschreibung            | Beispiel                  |
| ------------ | ----------------------- | ------------------------- |
| **Dichotom** | Nur 2 Ausprägungen      | krank/gesund, ja/nein     |
| **Polytom**  | Mehr als 2 Ausprägungen | Familienstand, Blutgruppe |

### Nach Messbarkeit

| Art                | Skalenniveaus         | Beschreibung                    | Beispiel               |
| ------------------ | --------------------- | ------------------------------- | ---------------------- |
| **Kategorial**     | Nominal, Ordinal      | Abzählbare, diskrete Kategorien | Geschlecht, Schulnote  |
| **Kontinuierlich** | Intervall, Verhältnis | Beliebige Werte möglich         | Reaktionszeit, Gewicht |

---

## Prüfungsrelevanz

**Must-Know:**

-   Merkmal → Variable → Daten
-   Latent vs. manifest
-   3 Gütekriterien (Objektivität, Reliabilität, Validität)
-   Hierarchie der Gütekriterien
-   4 Skalenniveaus mit Beispielen
-   Dichotom, kategorial, kontinuierlich
-   Beispiel Intervall vs. Verhältnis (Temperatur)

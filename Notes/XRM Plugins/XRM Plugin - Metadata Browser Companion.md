# Metadata Browser Companion

## Einordnung

- Bereich: Query, Metadata & Analysis
- Hersteller: MsCrmTools
- Version: 1.2025.7.27

## Kurzbeschreibung

Find the appropriate metadata right away from your Microsoft Dataverse environment or Microsoft Dynamics CRM organization

Im lokalen Setup bewusst behalten, weil die DLL auch den normalen Metadata Browser enthaelt.

## Wann ich es nutze

- Wenn ich Metadaten, Queries oder Datenstrukturen besser verstehen will.
- Wenn ich Abfragen validieren oder logische Namen schnell finden muss.
- Wenn ich Analysearbeit ohne Einmal-Code erledigen will.

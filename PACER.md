# P - Procedural

Das ist jede Information, die dir sagt, wie man etwas macht. es geht also um die richtige ausführung von irg was. zb Programmieren oder irg welche Sprachen. Die lernt man hald indem man sie praktiziert. So früh wie möglich beginnen mit dem ausführen. 


# A - Analagas

Das ist eine der einfachsten typen von information, weil sie in beziehung steht zu irg was worüber wir schon vorinformation haben oder uns an etwas erinnert. zb lernt man gut von strom, wenn man sich wasser vorstellt, weil das jeder kennt. das ist eine analogie.

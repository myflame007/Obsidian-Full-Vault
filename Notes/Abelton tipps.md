## Gain & Levels

- Gain kann gemapped werden auf MIDI
- **-15 bis -10 dB** ist guter Wert für parallele Bearbeitung (Parallel Compression)
- Im Effect Rack ist der Mixer rechts von den Effekten (= Output-Lautstärke)
- Headroom lassen: Master sollte nicht über **-6 dB** beim Produzieren

## Shortcuts

| Shortcut | Funktion |
|----------|----------|
| `Cmd + K` | Key Mapping (Keyboard zuweisen) |
| `Cmd + M` | MIDI Mapping |
| `Cmd + I` | Insert |
| `Cmd + D` | Duplizieren |
| `Cmd + R` | Umbenennen |
| `Cmd + G` | Gruppieren |
| `Cmd + J` | Clips zusammenführen (Consolidate) |
| `Cmd + E` | Clip am Playhead splitten |
| `Tab` | Session/Arrangement View wechseln |
| `0` | Clip/Track deaktivieren |

## Mapping

- **MIDI Learning**: Controller Knobs/Fader zuweisen
- **Key Learning**: Computer-Tastatur zuweisen
- Beide über `Cmd + M` / `Cmd + K` aktivieren

## Sampling & Warping

- **Re-Pitch**: Sample stretchen und dabei Tonhöhe an Song anpassen
- **Complex Pro**: Bester Warp-Modus für Vocals
- **Beats**: Für Drums/Percussion
- **Texture**: Für atmosphärische Sounds

## Plugins & Tools

- **Sonaworks (Reference)**: Room EQ / Kopfhörer-Kalibrierung

## Workflow-Tipps

- Farbcodierung für Tracks nutzen (Rechtsklick)
- Audio zu MIDI konvertieren: Rechtsklick auf Audio-Clip
- Freeze Track bei CPU-Last: Rechtsklick auf Track
- Return Tracks für gemeinsame Effekte (Reverb, Delay)
- Utility Plugin für schnelles Gain-Staging

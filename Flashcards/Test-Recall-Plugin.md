## Karte mit Memory Palace

Q: Was sind die 3 Säulen der Nachhaltigkeit?
A: 1. Ökologie 2. Ökonomie 3. Soziales
Hint: Die 3 E's auf Englisch: Environment, Economy, Equity
Memo: Stell dir einen dreibeinigen Hocker vor: Ein Bein ist ein grüner Baum (Ökologie), eines ist eine Goldmünze (Ökonomie), und das dritte zeigt Menschen die sich die Hände reichen (Soziales). Fehlt ein Bein, fällt der Hocker um.
Tags: nachhaltigkeit, test

## Die Schlüsselbeiträge

### George Miller (1920-2012)

#### "The Magical Number Seven, Plus or Minus Two"

**Die 7±2 Regel:**

-   Kapazität des Kurzzeitgedächtnisses
-   Wir können ca. 7 (±2) "Chunks" gleichzeitig im Bewusstsein halten

| Beispiel  | Anzahl Einheiten                         |
| --------- | ---------------------------------------- |
| 7 Ziffern | 7 Chunks                                 |
| 7 Wörter  | 7 Chunks                                 |
| 7 Sätze   | Auch 7 Chunks (wenn als Einheit kodiert) |

**Chunking:**

-   Zusammenfassen von Information zu größeren Einheiten
-   Ermöglicht mehr Speicherung

#### Das TOTE-Modell (Miller, Galanter & Pribram, 1960)

```
     ┌──────┐
     │ TEST │ ← Ist Ziel erreicht?
     └──┬───┘
        │
    Nein│          Ja
        ↓          ↓
   ┌────────┐   ┌──────┐
   │OPERATE │   │ EXIT │
   └───┬────┘   └──────┘
       │
       ↓
     TEST
       ...
```

-   **T**est: Vergleich Ist-Zustand mit Soll-Zustand
-   **O**perate: Handlung zur Zustandsänderung
-   **T**est: Erneute Prüfung
-   **E**xit: Verlassen bei Zielerreichung

**Bedeutung:**

-   Ersatz für S-R-Schema des Behaviorismus
-   Feedback-Schleifen, Zielorientierung
-   Grundlage für Handlungstheorien

### Noam Chomsky

#### Kritik an Skinners "Verbal Behavior" (1959)

**Argument:** Spracherwerb kann nicht durch Verstärkung erklärt werden

**Beweise:**

-   Kinder produzieren **neue Sätze**, die sie nie gehört haben
-   Überregularisierungen ("goed" statt "went")
-   Spracherwerb trotz "poverty of stimulus"

#### Universelle Grammatik

-   Angeborene Sprachfähigkeit
-   Tiefenstruktur vs. Oberflächenstruktur
-   Transformationsgrammatik

---

### Newell & Simon

#### Die Logiktheorie-Maschine (Logic Theorist)

**Erstes KI-Programm für Problemlösen**

-   Bewies mathematische Theoreme
-   Simulierte menschliches Denken
-   Nachweis: Mentale Prozesse können modelliert werden

## Grundannahmen der Kognitiven Psychologie

### Der Mensch als informationsverarbeitendes System

```
Input → Verarbeitung → Output
(Reiz)   (mental)     (Verhalten)
```

**Im Gegensatz zum Behaviorismus:**

-   Mentale Prozesse sind **zentral**, nicht irrelevant
-   Können wissenschaftlich untersucht werden
-   Computer als Metapher für den Geist

### Kognitive Prozesse

| Prozess            | Beschreibung                        |
| ------------------ | ----------------------------------- |
| **Aufmerksamkeit** | Selektion von Information           |
| **Wahrnehmung**    | Interpretation von Sinneseindrücken |
| **Gedächtnis**     | Speicherung und Abruf               |
| **Denken**         | Manipulation von Repräsentationen   |
| **Sprache**        | Symbolverarbeitung                  |

### Interne Handlungsziele

**Kernunterschied zum Behaviorismus:**

-   Nicht nur Reaktion auf Reize
-   Sondern: **Interne Ziele** steuern Verhalten
-   Proaktives, nicht nur reaktives Verhalten

## Die Informationsverarbeitungsmetapher

### Computer-Analogie

| Computer | Mensch             |
| -------- | ------------------ |
| Hardware | Gehirn             |
| Software | Kognitive Prozesse |
| Input    | Sinneseindrücke    |
| Speicher | Gedächtnis         |
| Output   | Verhalten          |

### Mehrspeichermodell (Atkinson & Shiffrin, 1968)

```
Sensorischer Speicher → Kurzzeitgedächtnis → Langzeitgedächtnis
     (Millisekunden)      (Sekunden)          (permanent)
```

## Donald Broadbent (1926-1993)

### Aufmerksamkeitsforschung

**Filtermodell (1958):**

-   Information wird früh gefiltert
-   Nur beachtete Information wird verarbeitet
-   "Flaschenhals" der Verarbeitung

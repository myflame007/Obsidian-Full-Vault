# Theorien und Hypothesen

> Von der Frage zur prüfbaren Vermutung

---

## Grundbegriffe

| Begriff       | Definition                                                              | Beispiel                                        |
| ------------- | ----------------------------------------------------------------------- | ----------------------------------------------- |
| **Theorie**   | Geordnete Menge von Begriffen und Aussagen zur Erklärung von Phänomenen | Bindungstheorie erklärt Beziehungsverhalten     |
| **Hypothese** | Konkrete, überprüfbare Vermutung über einen Sachverhalt                 | "Sichere Bindung führt zu besseren Beziehungen" |

```
Theorie (allgemein)
    ↓ Ableitung
Hypothese (spezifisch)
    ↓ Operationalisierung
Prüfbare Vorhersage
    ↓ Empirie
Ergebnis → bestätigt/widerlegt Hypothese
```

---

## Anforderungen an wissenschaftliche Hypothesen

### Die 4 Kriterien

| Kriterium                         | Beschreibung                                        | Gegenbeispiel                    |
| --------------------------------- | --------------------------------------------------- | -------------------------------- |
| **1. Präzise & widerspruchsfrei** | Eindeutig formuliert, kein Interpretationsspielraum | "Irgendwie beeinflusst X halt Y" |
| **2. Falsifizierbar**             | Muss prinzipiell widerlegbar sein                   | "Es gibt unsichtbare Kräfte"     |
| **3. Operationalisierbar**        | Begriffe müssen messbar sein                        | "Glück beeinflusst Karma"        |
| **4. Begründbar**                 | Auf Forschungsstand basierend                       | Reine Spekulation                |

### Falsifizierbarkeit (nach Popper)

> Eine Aussage ist nur dann wissenschaftlich, wenn sie **prinzipiell
> widerlegbar** ist

**Beispiele:**

| Aussage                           | Falsifizierbar? | Begründung                                |
| --------------------------------- | --------------- | ----------------------------------------- |
| "Alle Schwäne sind weiß"          | Ja              | Ein schwarzer Schwan widerlegt sie        |
| "Irgendwo gibt es Außerirdische"  | Nein            | Nicht widerlegbar (unendliches Universum) |
| "Therapie X hilft bei Depression" | Ja              | Messbar und prüfbar                       |

### Zeitpunkt der Hypothesenbildung

> **WICHTIG:** Hypothesen müssen **VOR** der Datensammlung aufgestellt werden!

**Warum?**

-   Vermeidung von p-Hacking (Daten solange analysieren, bis etwas signifikant
    wird)
-   Verhinderung von HARKing (Hypothesizing After Results are Known)
-   Sicherstellung echter Prüfung, nicht nachträglicher "Erklärung"

## Arten von Hypothesen

### Nach Inhalt

| Art                        | Beschreibung                               | Beispiel                                      |
| -------------------------- | ------------------------------------------ | --------------------------------------------- |
| **Unterschiedshypothese**  | Postuliert Unterschied zwischen Gruppen    | "Frauen zeigen höhere Empathie als Männer"    |
| **Zusammenhangshypothese** | Postuliert Zusammenhang zwischen Variablen | "Je mehr Stress, desto schlechter der Schlaf" |
| **Veränderungshypothese**  | Postuliert Veränderung über Zeit           | "Nach Therapie sinken die Angstwerte"         |

### Nach Richtung

| Art             | Beschreibung                                 | Beispiel                                           |
| --------------- | -------------------------------------------- | -------------------------------------------------- |
| **Ungerichtet** | Nur "es gibt einen Unterschied/Zusammenhang" | "Männer und Frauen unterscheiden sich in Empathie" |
| **Gerichtet**   | Gibt die Richtung an                         | "Frauen zeigen **höhere** Empathie als Männer"     |

**Statistisch:**

-   Ungerichtet → zweiseitiger Test
-   Gerichtet → einseitiger Test

## Kovariation und Kausalität

### Das Problem

```
A und B treten zusammen auf
        ↓
Bedeutet das, dass A → B verursacht?
        ↓
      NEIN!
```

> **Korrelation ≠ Kausalität!**

### Klassisches Beispiel

```
Eisverkauf steigt ────────── Ertrinkungsfälle steigen
           ↘                    ↙
              Temperatur (Drittvariable)
```

Der Eisverkauf verursacht keine Ertrinkungsfälle!

### Die 3 Bedingungen für Kausalität

| Bedingung                                   | Beschreibung                                                        | Prüfung                                     |
| ------------------------------------------- | ------------------------------------------------------------------- | ------------------------------------------- |
| **1. Kovariation**                          | A und B müssen zusammenhängen                                       | Korrelationsanalyse                         |
| **2. Zeitliche Abfolge**                    | A muss zeitlich VOR B auftreten                                     | Längsschnittdesign                          |
| **3. Ausschluss von Alternativerklärungen** | Keine andere Variable darf für den Zusammenhang verantwortlich sein | Kontrolle von Störvariablen, Randomisierung |

### Warum Experimente so wichtig sind

Nur im **Experiment** können alle 3 Bedingungen erfüllt werden:

| Bedingung               | Im Experiment                 |
| ----------------------- | ----------------------------- |
| Kovariation             | UV wird variiert, AV gemessen |
| Zeitliche Abfolge       | UV kommt vor AV               |
| Ausschluss Alternativen | Randomisierung, Kontrolle     |

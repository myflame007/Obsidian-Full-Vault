# Behaviorismus

> Psychologie als Wissenschaft des beobachtbaren Verhaltens

---

## Überblick

| Aspekt        | Information                               |
| ------------- | ----------------------------------------- |
| **Zeit**      | Ab ~1913                                  |
| **Ort**       | USA                                       |
| **Begründer** | John Watson                               |
| **Fokus**     | Beobachtbares Verhalten                   |
| **Ablehnung** | Introspektion, Bewusstsein als Gegenstand |

---

## Grundprinzipien

### Die "Black Box"

```
Stimulus (S) → [Black Box] → Response (R)
              (nicht beobachtbar)
```

-   Nur **Input** (Reiz) und **Output** (Reaktion) sind wissenschaftlich
    relevant
-   Mentale Prozesse sind nicht beobachtbar → werden ignoriert
-   Psychologie = objektive Naturwissenschaft

### Watsons Manifest (1913)

> "Psychology as the behaviorist views it"

**Forderungen:**

1. Psychologie = objektive Naturwissenschaft
2. Nur beobachtbares Verhalten ist Gegenstand
3. Ziel: Vorhersage und Kontrolle von Verhalten
4. Keine Introspektion, kein Bewusstsein

---

## Klassische Konditionierung

### Iwan Pawlow (1849-1936)

**Das berühmte Hundeexperiment**

| Phase       | Reiz            | Reaktion            |
| ----------- | --------------- | ------------------- |
| **Vor**     | Futter (UCS)    | Speichelfluss (UCR) |
| **Vor**     | Glocke (NS)     | Keine Reaktion      |
| **Während** | Glocke + Futter | Speichelfluss       |
| **Nach**    | Glocke (CS)     | Speichelfluss (CR)  |

**Begriffe:**

-   **UCS** = Unkonditionierter Stimulus (natürlicher Reiz)
-   **UCR** = Unkonditionierte Reaktion (natürliche Reaktion)
-   **CS** = Konditionierter Stimulus (gelernter Reiz)
-   **CR** = Konditionierte Reaktion (gelernte Reaktion)
-   **NS** = Neutraler Stimulus

### Wichtige Phänomene

| Phänomen            | Beschreibung                              |
| ------------------- | ----------------------------------------- |
| **Generalisierung** | Ähnliche Reize lösen gleiche Reaktion aus |
| **Diskrimination**  | Unterscheidung zwischen Reizen            |
| **Extinktion**      | Reaktion verschwindet ohne Verstärkung    |
| **Spontanerholung** | Reaktion kehrt nach Pause zurück          |

### Little Albert (Watson & Rayner, 1920)

-   9 Monate altes Kind
-   Konditionierung von Angst vor weißer Ratte
-   Generalisierung auf ähnliche Objekte (Pelz, Watte)
-   **Ethisch höchst problematisch!**

## Operante Konditionierung

### Edward Thorndike (1874-1949)

**Puzzlebox-Experimente mit Katzen**

**Law of Effect (Effektgesetz):**

> Verhalten, das zu befriedigenden Konsequenzen führt, wird verstärkt.

### B.F. Skinner (1904-1990)

**Skinnerbox:**

-   Kontrollierte Umgebung
-   Hebeldruck → Futter
-   Präzise Messung

### Verstärkungs- und Bestrafungsarten

|                 | Angenehm hinzufügen              | Unangenehm entfernen                 |
| --------------- | -------------------------------- | ------------------------------------ |
| **Verstärkung** | Positive Verstärkung (Belohnung) | Negative Verstärkung (Erleichterung) |

|                | Unangenehm hinzufügen        | Angenehm entfernen           |
| -------------- | ---------------------------- | ---------------------------- |
| **Bestrafung** | Positive Bestrafung (Strafe) | Negative Bestrafung (Entzug) |

**Beispiele:**

| Typ                  | Beispiel                      | Effekt           |
| -------------------- | ----------------------------- | ---------------- |
| Positive Verstärkung | Lob für gute Note             | Verhalten ↑      |
| Negative Verstärkung | Kopfschmerz weg nach Tablette | Tablettennahme ↑ |
| Positive Bestrafung  | Schimpfen nach Fehler         | Verhalten ↓      |
| Negative Bestrafung  | Handyentzug                   | Verhalten ↓      |

### Verstärkungspläne

| Plan            | Beschreibung            | Lernkurve                             |
| --------------- | ----------------------- | ------------------------------------- |
| Kontinuierlich  | Jede Reaktion verstärkt | Schnelles Lernen, schnelle Extinktion |
| Intermittierend | Nur manchmal verstärkt  | Langsameres Lernen, resistenter       |

## Neobehaviorismus

### Clark L. Hull (1884-1952)

**Erweiterung zum S-O-R-Schema:**

```
Stimulus → Organismus → Response
           (intervenierende Variable)
```

-   **Organismusvariable:** Hunger, Durst, Triebstärke
-   Mathematische Verhaltenstheorie
-   Versuch, alle Lernphänomene zu erklären

### Edward Tolman

-   **Kognitive Landkarten** bei Ratten
-   Latentes Lernen (ohne Verstärkung)
-   Zielgerichtetes Verhalten
-   Brücke zur Kognitiven Psychologie

## Kritik am Behaviorismus

| Kritikpunkt          | Beschreibung                               |
| -------------------- | ------------------------------------------ |
| **Reduktionistisch** | Ignoriert komplexe mentale Prozesse        |
| **Tierstudien**      | Übertragbarkeit auf Menschen fraglich      |
| **Sprache**          | Kann Spracherwerb nicht erklären (Chomsky) |
| **Kreativität**      | Kann neue Verhaltensweisen nicht erklären  |
| **Kognition**        | Denken, Planen werden ignoriert            |

> Diese Kritik führte zur **Kognitiven Wende** ab 1956!
